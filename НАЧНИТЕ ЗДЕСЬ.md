# Запуск личной библиотеки

## Первый раз

1. Установите [Docker Desktop](https://www.docker.com/products/docker-desktop/). Это программа, которая запускает библиотеку и всё необходимое для неё. Откройте Docker и закончите первоначальную настройку. Если Windows просит перезагрузить компьютер, выполните это.
2. Распакуйте папку **Yandex2Kindle** в удобное постоянное место. Не запускайте файлы прямо из ZIP-архива.
3. На **Mac** дважды нажмите **Запустить.command**, на **Windows** — **Запустить.bat**. Не закрывайте окно до открытия браузера. Первый запуск может занять несколько минут.
4. В открывшейся странице придумайте логин и пароль. Запишите пароль. Первый аккаунт получает право на настройку приложения.
5. Можно сразу перейти в библиотеку и добавить файл книги. Подключения Яндекса, почты и Telegram необязательны.

На Mac система может попросить подтвердить запуск скачанного файла. Если обычное открытие не разрешено, используйте контекстное меню файла → «Открыть» и подтвердите запуск. Если такой возможности нет, проверьте ограничения вашей системы; не отключайте системную защиту целиком.

## Где вводить ключи

Откройте **Настройки** в левой панели сайта. На телефоне сначала нажмите **Меню**.

- **Яндекс Книги:** нажмите «Войти в Яндекс», войдите в открывшейся вкладке, скопируйте её полный адрес после перехода и вставьте его в поле на сайте. Пароль Яндекса вводится только на странице Яндекса. Затем нажмите «Проверить подключение». Список переносится в разделе «Источники».
- **Отправка на Kindle:** нужны адрес исходящей почты (SMTP) и отдельный пароль приложения из настроек вашей почты. Укажите сервер, порт, логин, пароль приложения и адрес отправителя. Для STARTTLS обычно используется 587, для SSL — 465; точные данные возьмите у вашего почтового сервиса. Адрес отправителя нужно разрешить в аккаунте Amazon для Send to Kindle. Личную почту Kindle задайте в «Аккаунте».
- **Telegram:** создайте бота через `@BotFather`, вставьте токен и укажите свой Telegram ID или имя пользователя. Вы можете оставить Telegram неподключённым.
- **Каталоги:** добавляйте только знакомые вам адреса поиска. Если каталог не нужен, этот раздел можно пропустить.

Нажимайте **Сохранить**, затем **Проверить подключение**. Проверка SMTP не отправляет письмо, проверка Telegram не отправляет сообщение. «Сохранено» означает, что данные записаны; «Подключение проверено» — что сервис ответил на проверку.

Ключи хранятся на вашем компьютере в папке `data`. Сайт не показывает сохранённые ключи повторно. Если оставить секретное поле пустым, старый ключ сохранится. Для отключения есть отдельная кнопка. Настройки применяются без переустановки приложения; Telegram может обновляться до 30 секунд.

## В следующий раз

Откройте Docker Desktop и снова дважды нажмите файл запуска. Книги, аккаунт и подключения сохранятся. Обычно сайт доступен по адресу [localhost:8000](http://localhost:8000); если порт занят, запускатор подберёт другой и откроет правильный адрес.

## Подключение Kindle

Откройте **Устройства** на сайте. Там находятся адреса и инструкция. Компьютер и Kindle должны быть в одной домашней сети. Библиотека работает, пока компьютер включён и Docker запущен. При первом подключении ОС может запросить доступ приложения к локальной сети.

## Если не получилось

- **Docker не установлен:** запускатор откроет официальную страницу. После установки и первоначальной настройки запустите библиотеку ещё раз.
- **Docker долго запускается:** откройте его окно и завершите предложенные шаги. На Windows может понадобиться настроить WSL и перезагрузиться — следуйте подсказкам Docker.
- **Нет доступа к интернету:** для первой сборки и внешних подключений нужен интернет. Проверьте соединение и повторите запуск.
- **Страница создания аккаунта просит открыть файл запуска:** закройте её и ещё раз запустите приложение файлом. Право создать первый аккаунт передаётся через запускатор, а не через общедоступную регистрацию.
- **Ключ сохранён, но подключение не работает:** нажмите «Проверить подключение». Подсказка появится в соответствующем разделе настроек.
- **Нужна помощь с запуском:** подробности находятся в `data/launcher.log`. Не отправляйте помощникам `.env`, `setup.key`, `accounts.sqlite`, `configuration.sqlite` и всю папку `data`: там ваши личные данные.

Не удаляйте и не переносите отдельно папку `data`: в ней книги и настройки. Для переноса библиотеки на другой компьютер сначала остановите приложение и скопируйте всю папку Yandex2Kindle.

Для Linux с уже установленными Docker Engine, Compose и curl: `sh scripts/launch.sh`. Автоматическая установка Docker в Linux не выполняется.
