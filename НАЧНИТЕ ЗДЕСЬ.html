Ваша личная библиотека.

Для начала не нужны ключи, терминал и редактирование файлов.

Сначала — четыре шага

  1. Установите Docker Desktop с официального сайта. Откройте его и закончите первоначальную настройку. Если Windows предлагает перезагрузиться, сделайте это.
  2. Распакуйте папку Yandex2Kindle из ZIP в постоянное место.
  3. На Mac дважды нажмите Запустить.command, на Windows — Запустить.bat. Первый запуск может занять несколько минут; браузер откроется сам.
  4. Придумайте логин и пароль владельца. После этого можно сразу добавить EPUB или FB2 и читать.
На Mac скачанный файл может потребовать подтверждения: контекстное меню → «Открыть». Системную защиту целиком отключать не нужно.

Ключи вводятся на сайте

Откройте Настройки в меню библиотеки. Подключайте только то, что нужно:

  • Яндекс: «Войти в Яндекс» → скопировать адрес после входа → вставить его в форму. Пароль Яндекса вводится только на сайте Яндекса.
  • Kindle по почте: укажите данные SMTP и отдельный пароль приложения вашей почты. Адрес Kindle задаётся в «Аккаунте». Адрес отправителя нужно разрешить в Amazon Send to Kindle.
  • Telegram: токен от @BotFather и ваш ID или имя пользователя.

После сохранения нажмите «Проверить подключение». Настройки сохраняются между запусками. Пустое секретное поле оставляет прежний ключ; для отключения есть отдельная кнопка.

Следующий запуск

Откройте Docker и снова нажмите файл запуска. Не удаляйте папку data: там находятся ваши книги, аккаунты и настройки.

Что-то не получилось?

Если Docker отсутствует, запускатор откроет страницу установки. После установки запустите библиотеку снова. Если страница создания аккаунта предлагает открыть файл запуска, закройте вкладку и повторите запуск файлом.

Более подробная инструкция: НАЧНИТЕ ЗДЕСЬ.md. Диагностика запуска: data/launcher.log. Не передавайте посторонним всю папку data и файлы с ключами.

Приложение работает, пока компьютер включён и Docker запущен. Компьютер и Kindle должны находиться в одной домашней сети.
