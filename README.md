# Yandex2Kindle

**Версия: 1.0.0**

Личная библиотека на вашем компьютере: чтение EPUB в браузере, отправка книг на Kindle, полки, цитаты и синхронизация с KOReader.

## Быстрый запуск

1. Установите и откройте [Docker Desktop](https://www.docker.com/products/docker-desktop/).
2. Скачайте и распакуйте приложение. Запустите **Запустить.command** на macOS или **Запустить.bat** на Windows. На Linux с Docker Compose: `sh scripts/launch.sh`.
3. В открывшемся браузере создайте аккаунт и добавьте первую книгу.

Яндекс Книги, почта для Kindle и другие подключения настраиваются на сайте в **Настройках**. Для чтения загруженных книг ключи не нужны.

[Пошаговая установка](НАЧНИТЕ%20ЗДЕСЬ.md) · [Подробная справка](docs/reference.md)

## Возможности

- Библиотека с поиском, полками, фильтрами и редактированием метаданных.
- EPUB-ридер, аудиоплеер, цитаты и статистика чтения.
- Импорт файлов и папки `incoming`, конвертация через Calibre.
- Отправка на Kindle по почте, OPDS и плагин KOReader.
- Импорт списка Яндекс Книг и подключение внешних каталогов.

Синхронизация Яндекса переносит список книг, а не файлы подписки. Для обычного Kindle цитаты импортируются из `My Clippings.txt`; автоматическая отправка цитат доступна через плагин KOReader. Доступность внешних каталогов зависит от их работы и вашей сети.

## Обслуживание

- Ручной запуск: `docker compose up -d --build`, обычный адрес — `http://localhost:8000`.
- Забыли пароль: запустите **Восстановить пароль.command** или **Восстановить пароль.bat**.
- Резервная копия: сохраните папку `data` при остановленном приложении; если используете `.env`, сохраните его отдельно. Эти файлы содержат личные данные и ключи.
- Архив для передачи: `python3 scripts/package_release.py`. Личные данные в него не включаются.

Приложение предназначено для локального запуска. Для доступа через интернет необходима отдельная настройка HTTPS и защиты сервера.
