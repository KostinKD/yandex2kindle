# Компактная библиотека: дизайн и план реализации

Основание: пользователь поручил реализацию GAP-анализа и компактный дизайн без типовых декоративных приёмов. Работа в текущем checkout, без изменения данных рабочей библиотеки.

## Решения

Сохраняем FastAPI, серверный HTML, SQLite и обычный JS. Переносим сценарии, не код референсов. Тёплая бумага, графит, терракотовый акцент, Georgia для заголовков и локальный системный шрифт для управления. Радиусы 2–4 px, без градиентов, размытия и декоративных анимаций. Обложки служат основной графикой.

Каталог остаётся на `/`, отдельные `/dashboard`, `/wishlist`, `/devices`, `/books/{id}`. Компактная боковая навигация на desktop, доступное меню на телефоне. Библиотека: фильтры, сортировка, сетка/список, полки и загрузка по запросу. На странице книги: чтение, файлы, метаданные, прогресс, оценка, полки и цитаты. `/kindle` сохраняет облегчённый интерфейс.

Альтернативы: косметическое уплотнение не закрывает разрыв сценариев; перенос SPA потребует неоправданной миграции. Выбрано развитие текущих маршрутов и выделение каталога/представлений в отдельные Python-модули.

## Риски проверки

SQL-параметры из URL, пустой результат, Unicode/HTML в данных, потеря фильтра при пагинации, неизвестная книга, отдельные пользовательские БД, пустое название после trim, ограничения Calibre, CFI/XPointer/секунды, устаревший service worker.

## Границы этой поставки

Первая связная версия этапов 0–2 GAP-анализа. Автоматические metadata providers, объединение изданий, полноценный конвертер позиций, Kobo и двусторонняя синхронизация цитат остаются последующими подсистемами. Не создавать неподтверждённые статусы доставки и не обещать точную синхронизацию без преобразования.

## Результат и проверка

Реализованы каталог, страница книги, редактор метаданных, полки, отдельные dashboard/wishlist/devices и компактная адаптивная оболочка. Статус SMTP отделён от ручного подтверждения Kindle; публикация CFI/секунд в KOReader отключена. Уточнены возможности плагина и лимит загрузки. Старые HTML-ссылки фильтра wishlist перенаправляются на новую страницу. Service worker хранит только статику.

Зависимости установлены во временное окружение `/private/tmp/y2k-redesign-venv`, предпросмотр и браузерные изменения выполнялись на отдельной временной библиотеке. Рабочие файлы пользователя не использовались для мутаций. В локальных тестах следует задавать `LIBRARY_DIR`/`INCOMING_DIR` временными путями: часть старых фикстур подменяет только DB, иначе они пытаются использовать Docker-путь `/data`.

Проверки:

- 144 unittest: фильтры, пагинация, HTML escaping, частичные метаданные, снятие года, личные библиотеки, автоматические/ручные связи wishlist, SMTP и KOReader.
- Chromium: восемь страниц на ширинах 1440, 1024, 760 и 390 px, без горизонтального переполнения и pageerror.
- Браузерные действия: сохранение метаданных и отзыва, полки, открытие загрузки, добавление wishlist, тёмная тема/сохранение выбора, меню/Escape.
- Реальный EPUB в Foliate: fallback с XPointer на процент и позиция XPointer при 0%. В code review обнаружена путаница `goTo(number)`/`goToFraction`; воспроизведена в браузере и исправлена, включая переход по полосе прогресса. Рецензент подтвердил исправление.
- Python compileall, node --check для изменённых скриптов, git diff --check.

Ограничения: точного CFI/XPointer-конвертера нет; процент даёт ближайшую страницу. SMTP-проверки используют имитацию сервера. Метаданные в оригинале/Calibre не перезаписываются. Провайдеры, модель нескольких файлов, Kobo, динамические полки и полноценная синхронизация цитат остаются следующими этапами GAP-анализа.
