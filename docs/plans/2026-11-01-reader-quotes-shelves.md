# Исправления ридера, обмен цитатами и удаление полок

Основание: пользователь сообщил о неполной работе `/reader/5`, отсутствии цитат Kindle на сайте и невозможности удалить полки.

## Причины и изменения

- В ридере `.drawer` и `.highlight-bar` переопределяли браузерный `[hidden]`. В результате закрытые панели оставались видимыми. Добавлено явное правило скрытия.
- Невидимые tap-зоны перекрывали весь текст, включая центральные 70% экрана. Заменены небольшими кнопками перелистывания в полях; добавлена обработка клавиатуры внутри документа iframe.
- Цитаты сохраняли CFI текущей страницы вместо диапазона выделения, не отрисовывались при повторном открытии и показывали успех даже при HTTP-ошибке. Теперь используется `view.getCFI(index, range)`, Foliate Overlayer и проверка HTTP-ответа. Инициализация ожидает регистрацию custom element; ранние перемещения не перезаписывают сохранённую позицию.
- Управление полками добавлено в каталог. Повторное нажатие подтверждает удаление только полки; файлы, записи книг и прогресс сохраняются.
- Позиционный протокол KOReader не содержит цитат. Добавлен отдельный авторизованный `/syncs/highlights`, пакетная отправка плагином 1.1, сопоставление по хешу файла, изоляция библиотек, обновление заметок и tombstone для удалённых на сайте импортов. Привязка охватывает также конвертированный EPUB.
- Плагин получает общий список цитат с сайта в отдельный пункт меню. Обратная отрисовка веб-цитат в тексте KOReader не реализуется без конвертера позиций. Изменения границ выделения сохраняют `y2k_quote_id`; этот идентификатор живёт в sidecar-аннотации.
- Для штатного Kindle добавлен импорт UTF-8 `My Clippings.txt`: ru/en highlights, до 8 МБ, однозначное сопоставление книги, повторяемый импорт. Облачная синхронизация Amazon не заявляется.
- Docker-образ теперь содержит каталог плагина. Версии ресурсов и service worker обновлены.

## Проверка

- 152 Python unittest прошли, включая аутентификацию/изоляцию обмена, повторные импорты, ошибки сопоставления, tombstone и сохранность книг после удаления полки.
- 7 проверок Lua payload; синтаксис основного плагина проверен LuaJIT.
- Chromium на отдельной временной библиотеке с копией фактического конвертированного EPUB книги №5: закрытые панели, перелистывание, выделение, сохранение диапазона, восстановление подсветки, HTTP-ошибка, мобильная ширина, подтверждение удаления полки.
- `compileall`, `node --check`, `git diff --check`.
- Поведение API и плагина сверено с [исходниками ReaderAnnotation KOReader](https://github.com/koreader/koreader/blob/master/frontend/apps/reader/modules/readerannotation.lua). Физическое устройство не подключалось; сетевые события плагина требуют проверки на устройстве.

## Проверка пользователем

Обновить страницу ридера. Для KOReader заменить плагин из `/plugins/yandex2kindle.koplugin.zip`, перезапустить KOReader, задать URL сервера и учётные данные синхронизации со страницы «Аккаунт». Открыть книгу из личного OPDS и запустить «Синхронизировать цитаты этой книги». Для штатной читалки импортировать `documents/My Clippings.txt` в разделе «Цитаты». Для удаления полки раскрыть «Управление полками» в каталоге.
