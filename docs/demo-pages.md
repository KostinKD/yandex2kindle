# Статическое демо на GitHub Pages

Демо показывает библиотеку, полки, поиск, чтение трёх небольших глав, цитаты с Markdown-экспортом и обзор подключения устройств. Все тексты специально написаны для демо, обложки сделаны типографикой. Чужие книги и личные данные не используются.

Прогресс, выбранная полка, цитаты и тема сохраняются в localStorage этого браузера. Кнопка «Сбросить демо» восстанавливает начальное состояние. Отправки писем, загрузки файлов, API и настоящих подключений нет. Демо не запрашивает ключи и пароли.

## Публикация

1. В репозитории откройте Settings → Pages → Build and deployment → Source → GitHub Actions.
2. Отправьте изменения в `master`. Workflow `Deploy demo to GitHub Pages` соберёт и опубликует демо. Его также можно запустить через Actions → Run workflow.
3. После успешного деплоя адрес: `https://kostinkd.github.io/yandex2kindle/`.

Доступность Pages для приватного репозитория зависит от тарифа GitHub. Для бесплатного аккаунта обычно нужен публичный репозиторий. Изменение видимости не выполняется сборщиком или workflow.

## Локальная проверка

```sh
python3 scripts/build_demo.py --output /tmp/y2k-demo-preview
python3 -m http.server 8080 --directory /tmp/y2k-demo-preview
```

Откройте `http://localhost:8080`. Для повторной сборки выберите новую пустую папку. Непустая папка отвергается, чтобы старые или личные файлы не попали в публикацию.

Сборщик копирует только явный список HTML, JS, CSS, favicon и LICENSE. Не публикуйте весь репозиторий как Pages artifact: в демо не нужны серверные файлы, папки данных, ключи или архивы.

Стили берутся из основного приложения при сборке. Ссылки на ресурсы относительные, маршрутизация использует hash, поэтому демо работает в подпапке проекта без серверных перенаправлений.
